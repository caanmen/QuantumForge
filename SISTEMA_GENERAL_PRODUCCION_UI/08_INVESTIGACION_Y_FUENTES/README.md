# Investigación y fuentes

Esta carpeta conserva la procedencia de consejos incorporados al sistema. Su función es
permitir revisar vigencia y distinguir documentación oficial, postmortems, investigación y
experiencia comunitaria.

## Criterios

- Preferir documentación oficial y fuentes primarias para reglas técnicas.
- Tratar foros como señales y experiencias, no como verdad universal.
- Registrar fecha de revisión y versión cuando sea relevante.
- Convertir una fuente en una regla sólo si puede expresarse con alcance, prevención y prueba.
- No copiar consejos que contradigan mediciones del proyecto real.
- Revisar enlaces y vigencia antes de adoptar una herramienta o paquete archivado.

La síntesis operativa vive en las guías; esta carpeta conserva evidencia y contexto.

No se consulta completa por rutina. Se abre sólo cuando una guía seleccionada necesita
comprobar su procedencia, cuando la afirmación puede haber quedado desactualizada o cuando
el usuario solicita investigación. Antes de usar precios, versiones, políticas, librerías o
servicios actuales, se vuelve a verificar la fuente oficial vigente.
