# Proyectos

Cada proyecto registrado tiene exactamente una carpeta propia aquí. Contiene únicamente sus
políticas, decisiones, estado, evidencias, pruebas y herramientas específicas. Un videojuego
puede añadir perfiles visuales, assets documentales, referencias y capturas.

Reglas:

- No usar un proyecto como plantilla creativa de otro.
- No promover una decisión específica al núcleo sin depurar alcance, causa y prueba.
- Mantener las rutas de cada juego bajo su carpeta estable.
- Los assets runtime continúan donde el motor los necesita; esta zona conserva su autoridad
  documental y evidencia.
- Al adoptar el sistema en un proyecto nuevo, crear una carpeta nueva sólo si necesita
  autoridad documental compartida.
- El enrutador abre únicamente la carpeta del proyecto activo. Los proyectos anteriores se
  excluyen salvo que una regla aplicable enlace un caso histórico concreto.
