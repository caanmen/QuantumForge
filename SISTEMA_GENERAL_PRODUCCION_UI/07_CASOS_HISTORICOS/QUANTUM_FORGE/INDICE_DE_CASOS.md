# Índice resumido de casos: Quantum Forge

Este índice conserva trazabilidad sin duplicar las imágenes ni la documentación completa del
proyecto. La evidencia original permanece en SISTEMA_GENERAL_PRODUCCION_UI/09_PROYECTOS/QUANTUM_FORGE.

| Regla | Caso de origen resumido | Aprendizaje transferible | No heredar |
|---|---|---|---|
| UI-GEN-002 | Textos y geometría recibían escrituras de controladores distintos | Asignar un propietario por propiedad y probar en varios momentos | Nombres, layout y controladores del juego |
| UI-GEN-003 | Se recrearon iconos y composiciones que ya tenían recursos utilizables | Auditar el proyecto real antes de producir candidatos | Paleta, iconos o estética de una dimensión |
| UI-GEN-004 | Una composición técnicamente válida redujo arte detallado a formas genéricas | Fidelidad incluye medio, densidad, topología y ocupación | El porcentaje o referencia concreta del juego |
| UI-GEN-006 | Tarjetas usaban índices que no coincidían con el orden funcional | Vincular por ID estable y resolver el índice después | Destinos, sectores y nombres concretos |
| UI-GEN-007 | Métodos directos pasaban aunque los botones reales no recibían eventos | Probar el recorrido mediante el sistema de entrada real | Jerarquía de navegación específica |
| UI-GEN-008 | Se revisó una captura anterior después de fallar la ejecución nueva | Toda evidencia se valida por versión, fecha y PASS específico | Nombres y rutas de capturas |
| UI-GEN-009 | Un escenario visual ficticio pudo alcanzar el guardado al cerrar el motor | Proteger persistencia durante todo el ciclo de QA | Valores, archivo y progresión concretos |
| UI-GEN-010 | Una build creció por texturas enlazadas a producción | Medir dependencias y coste real antes de optimizar | Tamaños de build y formato de entrega concretos |
| UI-UGUI-001 | Fondos y targetGraphic incorrectos dejaron controles visibles pero inertes | Verificar raycast físico y quitar eventos de adornos | Componentes y nombres de raíces concretas |
| UI-UGUI-002 | Constructores históricos podían reconstruir la misma raíz de formas distintas | Mantener un constructor canónico idempotente | Menús y scripts del proyecto |
| UI-MOB-001 | Controles conectados eran difíciles de descubrir en la resolución menor | Medir señal visual y superficie táctil final | Resoluciones fijas del proyecto |
| UI-MOB-002 | Una actualización podía exigir reinstalación y poner en riesgo el avance | Conservar identidad y probar actualización respaldada | Paquete, firma, SDK y guardado concretos |
| UI-GEN-015 | Se desplazó y amplió un artefacto aprobado para intentar hacerlo coincidir con un marco de suelo incorrecto | Bloquear el objeto aprobado y corregir el asset propietario del marco, apoyo u oclusión | El Monolito, su escala, el laboratorio y las coordenadas concretas |

La bitácora y las guías específicas de Quantum Forge contienen muchos más detalles. Este
índice deliberadamente conserva sólo la parte útil fuera del juego.
