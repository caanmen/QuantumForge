# Casos históricos

Los casos muestran dónde se descubrió una regla y qué evidencia la respaldó. No son una
plantilla artística, mecánica ni técnica obligatoria para otros proyectos.

No se leen todos al iniciar un proyecto o chat. Se consulta un caso únicamente cuando el
catálogo o una guía aplicable lo enlaza, cuando coincide con el mismo tipo de causa o cuando
hace falta revisar la evidencia que originó una regla. Conocer el índice es suficiente para
saber que existen.

Cada caso debe incluir:

- Proyecto y fecha.
- Pantalla o sistema de origen.
- Síntoma y causa comprobada.
- Solución aplicada.
- Regla general extraída y su ID.
- Elementos del caso que NO deben heredarse.
- Evidencia disponible dentro del proyecto de origen.

Para copiar este sistema a otro proyecto basta conservar los resúmenes textuales. Los assets,
capturas y logs completos permanecen en su proyecto de origen.
