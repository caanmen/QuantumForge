# Mockups de producción — Dimensión 1

Propuestas visuales verticales basadas en las pantallas y estados existentes en
`Dimension1PanelUI`. Son referencias de distribución y lenguaje visual; no
assets finales de juego.

Regla de fidelidad: cada elemento visible debe poder resolverse con UGUI/TMP,
sprites 9-slice, ParticleSystem, Shader Graph simple, mallas URP Lit de detalle
medio o RenderTexture.
